## Installation

1. Open your terminal or command prompt and run the following command:
>git clone https://github.com/ACastilleja/arturo-castilleja-mars.git

2. Navigate to the Project Folder:
>cd arturo-castilleja-mars

3. Open the Project by opening the forder in VS Code and right-clicking on index.html and selecting "Open with Live Server".

## Usage

1. Use any of the navigation links at the top to quickly move around my portfolio page.  

2. If you would like to leave me a message and your email you can do this by using the Leave a Message form at the bottom of my portfolio page and hitting submit.  

3. You can also contact me by clicking any of the social media icons in the Connect section and this will take you to my Github or Linkedin page or send me and email.
